# E-commerce Sales Analysis Project

## 📊 Overview
This project is an end-to-end e-commerce sales analysis solution built using **MySQL Workbench** and **Microsoft Excel**. It aims to analyze customer ordering patterns, product performance, and sales revenue to extract key business insights.

## 🛠️ Tools & Technologies
- **Database Management & Querying:** MySQL Workbench
- **Data Visualization & Dashboard:** Microsoft Excel (Pivot Tables, Charts, Slicers, KPI Cards)

## 🔍 Key Analysis & SQL Queries
- Calculated **Total Sales** and **Total Profit** using aggregate functions (`SUM`).
- Performed **Category-wise Sales Analysis** (Electronics, Furniture, Clothing, Accessories).
- Identified **Top 5 Best-Selling Products** using `GROUP BY` and `ORDER BY DESC`.
- Analyzed regional performance through **Region-wise Sales Distribution**.

## 📁 Repository Files
- `Ecommerce sales dashboard project.sql`: Contains all core analytical SQL queries.
- `Ecommerce_Sales_Analysis_dashboard.xlsx`: Interactive Excel dashboard visualizing sales metrics.
